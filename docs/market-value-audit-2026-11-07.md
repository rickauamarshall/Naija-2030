# Market-value audit — November 7, 2026

## Method

- Manual, one-player-at-a-time Transfermarkt cross-reference; no automated
  scraping or API use.
- Values shown on the site are rounded USD display figures. The comparison
  currency is the source's EUR market value, using the tracker display rate
  of roughly EUR1 = USD1.14 for this update.
- A value is not a transfer fee, a projection, or a ranking instruction.
- `TBD` remains the correct label where a current, attributable senior value
  could not be established. It must not be replaced with a made-up estimate.
